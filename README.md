# Littera Reader

Lector de libros multiformato para Android: **EPUB, PDF, DOCX y TXT** en una sola app. 100% offline, sin cuentas y sin nube: tus libros viven en tu teléfono.

- Biblioteca local con portadas y progreso de lectura
- Temas claro, oscuro y sepia, con tamaño de letra ajustable
- Lectura en voz alta (TTS) integrada
- Marcadores y reanudación exacta donde lo dejaste
